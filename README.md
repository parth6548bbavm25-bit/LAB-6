Topic: Security and Privacy Audit — PII-Safe Prompting
PII: Names, phone numbers, emails, passport/Aadhaar numbers, PNRs, payment information, medical information, etc.
Aviation data sensitivity: Passenger, employee, booking, baggage, medical, security and operational information.
Unsafe prompt analysis: Identifying privacy and accuracy risks.
Safe placeholders: Replacing real information with placeholders such as [PASSENGER NAME] and [VERIFY AIRLINE POLICY].
Safe prompt: Creating an email without exposing personal or confidential information.
Information classification: Public, Internal, Confidential, and Restricted/Highly Sensitive.
PII detection challenge: Flight cancellation, special assistance, employee report and payment complaint.
Data minimisation: Providing only the information necessary for the task.
Security audit: Checking prompts for PII, credentials, confidential data and verification requirements.
Privacy-safe aviation prompt: Creating an original prompt using fictional details/placeholders.
GitHub safety: Confirming that no real PII or confidential information is uploaded.
